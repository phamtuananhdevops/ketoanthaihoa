    1. Đầu mối server POST /api/ai — key của chủ app nằm ở Environment Variables phía server. Có đầu mối này là mọi người dùng dùng chung, không ai phải nhập token và không ai thấy key. Đây là cách chạy chính trên bản publish.
    2. Token phiên cá nhân (form bên dưới) — chỉ dùng khi chưa có /api/ai, ví dụ đang xem bản tĩnh này. App tự chuyển xuống đường này nếu /api/ai chưa được triển khai hoặc chưa cấu hình key.
    3. Bộ quy tắc nội bộ offline — khi cả hai đường trên đều chưa nối: ghi sổ, tính thuế / lương / khấu hao và gợi ý định khoản cơ bản vẫn chạy, chỉ thiếu phân tích sâu của AI.

    🔑 Token cá nhân — phương án dự phòng

    Chỉ cần điền khi bản đang xem chưa có đầu mối server. Trên bản publish đã có /api/ai thì bỏ qua mục này — mọi tính năng AI đã chạy bằng key phía server.

    Bảo mật: Token dự phòng chỉ giữ trong bộ nhớ của phiên làm việc này, không lưu xuống máy, không gửi đi nơi khác. Đóng tab là token mất và phải dán lại. Tuyệt đối không dán token của chủ app vào bản HTML khi publish công khai — key dùng chung phải đặt ở biến môi trường phía server (xem phần serverless bên dưới).

    Đầu mối chung mở những gì?

    • ✅ Không cần AI: ghi sổ, hóa đơn & GTGT, công nợ, lương, TSCĐ, dòng tiền, gợi ý định khoản bằng bộ quy tắc nội bộ — chạy ngay, offline.
    • 🧠 Có đầu mối (server hoặc token phiên): trợ lý AI nâng cao dùng chung một đường gọi — đọc hóa đơn từ ảnh / PDF và tự điền form ở mục Hóa đơn, phân tích diễn giải tự do, soạn công văn giải trình thuế, nháp thuyết minh BCTC, tóm tắt văn bản thuế, soát chứng từ bằng ngôn ngữ tự nhiên.
    • 📤 Đọc hóa đơn bằng AI: mở mục Hóa đơn & GTGT, chọn file rồi bấm “Đọc bằng AI & điền vào form”. Kết quả chỉ điền sẵn để bạn kiểm tra — bấm Lưu mới ghi vào bảng kê.
    • ⚠️ Gọi AI trực tiếp từ trình duyệt bằng token cá nhân có thể bị nhà cung cấp chặn CORS — đó là lý do đường chính khi publish là hàm serverless /api/ai giữ key phía server.

    🧠 Đầu mối AI chung cho toàn app — một chỗ, mọi tính năng

    Thay vì mỗi tính năng tự gọi AI một kiểu, KetoanAI gom mọi lượt gọi AI về một đầu mối duy nhất trong mã của trang (callAIHubText cho văn bản, callInvoiceAI cho hóa đơn — cả hai cùng thử /api/ai trước, cùng fallback): gợi ý định khoản, đọc hóa đơn từ ảnh / PDF, hỏi đáp tự do, soạn công văn, tóm tắt văn bản và soát chứng từ đều đi qua cùng một system prompt kế toán và cùng một kho ngữ cảnh do buildAIContext() tổng hợp. Sửa prompt hoặc kho ở một chỗ là mọi tính năng cùng giỏi lên — và khi đầu mối chạy phía server, sửa ở server là mọi người dùng được hưởng ngay, không ai thấy prompt / kho đó.

    Trạng thái đầu mối: Đang kiểm tra /api/ai…

    1 · System prompt chung

    Vai trò kế toán Việt Nam, chế độ TT 200 / 133, bắt trích dẫn số hiệu văn bản, không bịa số liệu, và nguyên tắc bất biến: AI chỉ chuẩn bị — người có thẩm quyền mới ký và nộp. Mọi điểm gọi AI trong trang này đều tự động kèm prompt này; bản serverless giữ một bản giống hệt ở phía server.

    2 · Kho kiến thức đi kèm (RAG gọn)

    Mỗi lượt gọi tự động đính kèm ngữ cảnh do app tự tổng hợp: các ngưỡng luật đang thực sự dùng để tính (đã Update luật 2026 hay chưa), toàn bộ danh mục thư viện văn bản theo chủ đề kèm số hiệu, và số lượng chứng từ / hóa đơn / dòng lương hiện có — để AI trả lời dựa trên tài liệu của app thay vì nhớ mang máng. Luật mới thì chỉ cần cập nhật kho này, không phải train lại gì.

    3 · Ví dụ mẫu chuẩn

    Ngữ cảnh luôn kèm vài cặp hỏi — đáp mẫu đã kiểm chứng (định khoản mua hàng, bán hàng, trích khấu hao) để AI bắt chước đúng cách lập luận và trình bày của app, thay vì trả lời tự do mỗi lần một kiểu.

    4 · Số liệu do app tính

    Thuế, lương, khấu hao, dòng tiền luôn do công thức của app tính trước; AI chỉ diễn giải kết quả và chỉ ra căn cứ. Không để AI tự nhẩm số — đó là chỗ LLM hay sai nhất.

    // api/ai.js — Đầu mối AI chung KetoanAI (Vercel Serverless Function)
// Key đọc từ Environment Variables phía server — KHÔNG nhúng vào HTML, KHÔNG gửi qua chat.
// Hợp đồng với app:
//   POST { "ping": true }                                  -> { ok, configured, provider }  (không gọi AI, không tốn token)
//   POST { "prompt": "...", "context": "..." }             -> { text }                      (hỏi đáp / định khoản / công văn)
//   POST { "prompt": "...", "context": "...",
//          "image": { "mime": "image/jpeg", "data": "..." } } -> { text }                 (đọc hóa đơn, data là base64)
// Nhà cung cấp tự chọn theo key có mặt: ANTHROPIC_API_KEY > OPENAI_API_KEY > GEMINI_API_KEY.
// Đổi model bằng biến AI_MODEL nếu muốn.

const SYSTEM_PROMPT = `Bạn là trợ lý kế toán — thuế Việt Nam của KetoanAI.
- Trả lời theo chế độ kế toán TT 200/2014 và TT 133/2016, luật thuế hiện hành.
- Luôn trích dẫn số hiệu văn bản khi nêu căn cứ; không chắc thì nói rõ là chưa chắc, không bịa số liệu, ngưỡng hay số hiệu.
- Số tiền, thuế, lương, khấu hao: chỉ diễn giải số do app cung cấp trong ngữ cảnh, không tự nhẩm lại.
- Nguyên tắc: AI chỉ chuẩn bị và gợi ý — người có thẩm quyền mới ký và nộp hồ sơ.`;

function pickProvider() {
  if (process.env.ANTHROPIC_API_KEY) return { name: "anthropic", key: process.env.ANTHROPIC_API_KEY, model: process.env.AI_MODEL || "claude-sonnet-4-5" };
  if (process.env.OPENAI_API_KEY) return { name: "openai", key: process.env.OPENAI_API_KEY, model: process.env.AI_MODEL || "gpt-4o" };
  if (process.env.GEMINI_API_KEY) return { name: "google", key: process.env.GEMINI_API_KEY, model: process.env.AI_MODEL || "gemini-2.0-flash" };
  return null;
}

export default async function handler(req, res) {
  if (req.method !== "POST") return res.status(405).json({ error: "Method not allowed" });
  const body = typeof req.body === "string" ? JSON.parse(req.body || "{}") : (req.body || {});
  const prov = pickProvider();
  if (body.ping) return res.status(200).json({ ok: true, configured: !!prov, provider: prov ? prov.name : null });
  if (!prov) return res.status(500).json({ error: "Server chưa cấu hình key AI (ANTHROPIC_API_KEY / OPENAI_API_KEY / GEMINI_API_KEY)" });

  const prompt = String(body.prompt || "").slice(0, 8000);       // giới hạn độ dài đầu vào
  const context = String(body.context || "").slice(0, 12000);   // ngữ cảnh do app tổng hợp
  if (!prompt) return res.status(400).json({ error: "Thiếu prompt" });
  const image = body.image && body.image.data ? body.image : null;
  if (image && String(image.data).length > 14000000) return res.status(413).json({ error: "File quá lớn" });
  // TODO khi mở công khai: thêm rate-limit theo IP / ngày ở đây, trước khi gọi nhà cung cấp.

  const system = SYSTEM_PROMPT + "\n\nNGỮ CẢNH TỪ APP:\n" + context;
  let r, j;
  if (prov.name === "anthropic") {
    const content = [];
    if (image) content.push(image.mime === "application/pdf"
      ? { type: "document", source: { type: "base64", media_type: "application/pdf", data: image.data } }
      : { type: "image", source: { type: "base64", media_type: image.mime, data: image.data } });
    content.push({ type: "text", text: prompt });
    r = await fetch("https://api.anthropic.com/v1/messages", { method: "POST",
      headers: { "Content-Type": "application/json", "x-api-key": prov.key, "anthropic-version": "2023-06-01" },
      body: JSON.stringify({ model: prov.model, max_tokens: 1500, system, messages: [{ role: "user", content }] }) });
    j = await r.json();
    if (!r.ok) return res.status(r.status).json({ error: (j.error && j.error.message) || "AI provider error" });
    return res.status(200).json({ text: (j.content || []).map(c => c.text || "").join("") });
  }
  if (prov.name === "google") {
    const parts = [];
    if (image) parts.push({ inlineData: { mimeType: image.mime, data: image.data } });
    parts.push({ text: prompt });
    r = await fetch("https://generativelanguage.googleapis.com/v1beta/models/" + prov.model + ":generateContent", { method: "POST",
      headers: { "Content-Type": "application/json", "x-goog-api-key": prov.key },
      body: JSON.stringify({ systemInstruction: { parts: [{ text: system }] }, contents: [{ parts }], generationConfig: { maxOutputTokens: 1500 } }) });
    j = await r.json();
    if (!r.ok) return res.status(r.status).json({ error: (j.error && j.error.message) || "AI provider error" });
    const p2 = (j.candidates && j.candidates[0] && j.candidates[0].content && j.candidates[0].content.parts) || [];
    return res.status(200).json({ text: p2.map(x => x.text || "").join("") });
  }
  // openai (tương thích OpenAI) — đường này chỉ nhận ảnh, không nhận PDF
  if (image && image.mime === "application/pdf") return res.status(400).json({ error: "OpenAI không nhận PDF qua đầu mối — dùng ảnh, hoặc cấu hình Claude / Gemini" });
  const userContent = image
    ? [{ type: "image_url", image_url: { url: "data:" + image.mime + ";base64," + image.data } }, { type: "text", text: prompt }]
    : prompt;
  r = await fetch("https://api.openai.com/v1/chat/completions", { method: "POST",
    headers: { "Content-Type": "application/json", "Authorization": "Bearer " + prov.key },
    body: JSON.stringify({ model: prov.model, max_tokens: 1500, messages: [{ role: "system", content: system }, { role: "user", content: userContent }] }) });
  j = await r.json();
  if (!r.ok) return res.status(r.status).json({ error: (j.error && j.error.message) || "AI provider error" });
  return res.status(200).json({ text: (j.choices && j.choices[0] && j.choices[0].message && j.choices[0].message.content) || "" });
}
